# Global Supply Chain: Predictive Analytics for Late Delivery Risk

## 📊 Business Overview
In global logistics, late deliveries are more than a delay—they represent a significant drain on revenue and customer trust. This project analyzes **180,519 records** from a global supply chain to identify bottlenecks and predict shipping risks before they occur.

## 🚀 Key Insights & Impact
* **High-Risk Identification:** Identified a **54.8% late delivery rate** across the dataset, with specialized categories like **Golf Bags & Carts** reaching a **68.9% risk factor**.
* **Predictive Power:** Developed a Random Forest machine learning model capable of predicting late deliveries with **97% accuracy**.
* **Reliability:** Validated the model using **5-Fold Cross-Validation**, achieving a consistent **0.97 Mean Score**, proving the model is stable and ready for real-world deployment.

## 🛠️ Technical Stack
* **Language:** Python 3
* **Libraries:** Pandas, NumPy, Scikit-Learn, Matplotlib, Seaborn
* **Techniques:** Feature Engineering, Binary Classification, K-Fold Cross-Validation, Data Visualization

## 📈 Results
The final model provides a data-backed roadmap for carrier optimization. By flagging high-risk shipments at the point of order, companies can proactively adjust shipping modes or carriers to mitigate delays.
